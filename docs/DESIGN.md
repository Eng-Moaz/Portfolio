# The Engineering Notebook

A personal notebook for Moaz Mohamed. Preserve warm paper, Fraunces editorial headings, Inter text, and a restrained navy dark theme. Original composition inspired by the personal, playful quality of the reference, without copying its layout or artwork.

## Content-integrated navigation

No conventional navbar, sidebar navigation, dock, or hamburger. The introduction has a circled GitHub link and a handwritten trail into the project drawer. Section links lead to the full work, writing, experiment, and log archives. Every detail and archive page links back to the notebook. The independent theme button sits in the page margin. No section numbering.

## Personality with purpose

An original pencil orbit holds gently drifting handwritten technology labels. Labels deliberately avoid imitating branded logos. The name's pencil underline extends on hover; the name remains plain readable text. The margin notes point to content, rather than decorating every heading. Reduced motion disables animation and transitions; nothing requires hover to read or navigate.

## Project drawer

Keep the tab-and-evidence interaction. Give images a full row and descriptions their own flow to prevent collisions. Two artifacts overlap lightly like photographs; captions and core copy remain readable. Desktop pointer hover and keyboard focus preview; mouse click opens the project. Arrow keys select tabs. Touch selects a project and uses the explicit Open project link. An empty collection has a graceful fallback.

## Reading and rhythm

A compact introduction, project drawer, writing list, paired brief previews, and contribution calendar form the home index. Essays use a 700px reading column, restrained sticky desktop contents and an expandable mobile contents control. Code, tables, images, blockquotes and callouts carry meaning. Public output never presents sample essays or metrics as Moaz's work.

## Color and motion

Paper #f7f4eb, ink #232638, accessible blue #526397, coral #a95047. Dark mode uses navy paper, warm white text, and lighter accents. Float animations move a few pixels at independent speeds using CSS transforms. Static geometry and explicit image dimensions limit layout shifts. Visible focus outlines and standard links remain throughout.
