# The Engineering Notebook

Moaz Mohamed is the sole public identity; notebook describes an aesthetic, not a separate brand. Preserve warm paper, Fraunces editorial headings, Inter text, and a restrained navy dark theme. Original composition inspired by the personal, playful quality of the reference, without copying its layout or artwork.

## Content-integrated navigation

No conventional navbar, sidebar navigation, dock, or hamburger. The introduction has icon-led GitHub and email links and a handwritten About link. Section links lead to work and writing. The homepage no longer promotes a lab or experiments archive. Every detail and archive page links back to the main page. The theme button sits in the page margin beside a CV download only when the real PDF exists. No section numbering.

## Personality with purpose

An original pencil orbit holds gently drifting authentic Docker, PyTorch, Go, and Kubernetes logos on warm paper stickers. Artwork is unmodified, served locally, and documented in ASSETS.md. The name's pencil underline extends on hover; the name remains plain readable text. The margin notes point to content, rather than decorating every heading. Reduced motion disables animation and transitions; nothing requires hover to read or navigate.

## Project drawer

Keep the tab-and-evidence interaction. Give images a full row and descriptions their own flow to prevent collisions. Two artifacts overlap lightly like photographs; captions and core copy remain readable. Desktop pointer hover and keyboard focus preview; mouse click opens the project. Arrow keys select tabs. Touch selects a project and uses the explicit Open project link. An empty collection has a graceful fallback.

## Reading and rhythm

A compact introduction, project drawer, writing list, a small engineering log, and contribution calendar form the home index. Essays use a 700px reading column, restrained sticky desktop contents and an expandable mobile contents control. Code, tables, images, blockquotes and callouts carry meaning. Public output never presents sample essays or metrics as Moaz's work.

## Color and motion

Paper #f7f4eb, ink #232638, accessible blue #526397, coral #a95047. Dark mode uses navy paper, warm white text, and lighter accents. Float animations move a few pixels at independent speeds using CSS transforms. Static geometry and explicit image dimensions limit layout shifts. Visible focus outlines and standard links remain throughout.

## Final refinements

The GitHub activity link is typographic with one original pencil arrow; no pill beside the graph. Code blocks are typeset notebook inserts using JetBrains Mono, a warm paper / charcoal pair, restrained syntax accents, thin borders and a small integrated copy control. Rosé Pine Dawn/Moon and the custom Notebook themes were compared in the browser; Notebook was selected for warmer dark mode and better comment contrast. All selected syntax token colors pass 4.5:1 against their respective code background. The introduction, overall palette, spacing and overlapping project drawer remain intact.

## Personal refinement

Six compact stickers (Docker, PyTorch, Go, Kubernetes, AWS and Terraform) follow independent four-point CSS floats with staggered phases. The central star is removed. Reduced motion freezes stickers and shows the full handmade name underline. The underline starts beneath Moaz. About uses plain editorial paragraphs and optional snapshot groups, not hobby cards. Project case studies share blog typography, contextual figures, code controls and a responsive table of contents. The drawer remains overlapping previews. Logs remain source-only.
