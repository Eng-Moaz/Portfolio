# Asset provenance

## Technology stickers

Unmodified Docker, PyTorch, Go wordmark, Kubernetes, AWS, Terraform and GitHub SVGs from [Devicon v2.17.0](https://github.com/devicons/devicon/tree/v2.17.0/icons). Source paths: `icons/docker/docker-original.svg`, `icons/pytorch/pytorch-original.svg`, `icons/go/go-original-wordmark.svg`, `icons/kubernetes/kubernetes-original.svg`, `icons/amazonwebservices/amazonwebservices-original-wordmark.svg`, `icons/terraform/terraform-original.svg`, `icons/github/github-original.svg`. A copy of the collection's MIT license is in `public/images/logos/DEVICON-LICENSE.txt`.

Logos identify technologies only and do not imply endorsement. Brand trademarks remain with their owners; retain their shapes, aspect ratios, colors and clear space. The surrounding paper and pencil orbits are original site artwork. SVGs are served locally; no runtime icon CDN or third-party script is involved.

## Project artifacts

Activity-recognition architecture and baseline b1 confusion matrix were fetched from Eng-Moaz/Deep-Activity-Recognition, revision `1c7160a349997d29eae9673faaaca7c13e15fb42` (source paths are pinned in the case study). The case-study page links the exact repository paths for provenance and original attribution. The architectural research is credited to Ibrahim et al., CVPR 2016. WebP versions preserve the visuals at bounded dimensions. Other project studies are original vector placeholders and have `sample: true` in their media metadata.

The About photo slots are original CSS placeholders explicitly labeled as such, not generated photographs. Replace them with Moaz’s own images. The envelope and download line icons are original inline SVG; the GitHub mask uses the licensed Devicon silhouette.
