# Source images

Store publishable originals here so Astro can optimize them at build time.

- `about/` — personal photographs and environment screenshots
- `projects/<slug>/` — project screenshots and diagrams
- `writing/<slug>/` — article images
- `certificates/` — privacy-reviewed certificate thumbnails

See `docs/ASSETS.md` before committing personal media. Files in this directory are source-controlled and are not private.
